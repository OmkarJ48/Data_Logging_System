Channel Selector

  • Open the channel selector interface on your screen.
  • Select the channel you want to display.
  • Click to confirm your selection.

Channel Configuration

  • Click the name of the channel you want to configure.
  • Update Max Range, Gauge Code and Transducer Code.
  • Review all parameters, then close the tab when finished.

Note: Calibration Offset is used to adjust the zero point of the measurement.

Channel Monitor

  • Find the list of available channels displayed on the screen.

Start Button

  1. Button to open Start dialogs.
    Note:
    • There are 5 different start dialogs depending on the selected test.

    Start Automation

    • Click the start button for the dialog box.
    • Enter the required information in the fields provided.
    • Click Start to begin the test.

    Note: The Open and Close programme includes an additional allowable drop input, which can be toggled between percentage and psi. This is used to calculate stabilisation when performing an open and close operation with equalised pressure.

    Start Cycles

    • Click the start button for the dialog box.
    • Enter the required information in the fields provided.
    • Click Start to begin the test.

    Note: The tick boxes represent recorded cycles. Depending on the operation, the programme will either automatically calculate the breakout value or prompt you to enter it manually.

    Start Hold

    • Click the start button for the dialog box.
    • Enter the required information in the fields provided.
    • Click Start to begin the test.

    Start Temperature

    • Click the start button for the dialog box.
    • Enter the required information in the fields provided.
    • Click Start to begin the test.

      Details

      Overview of the Details interface and functions. Choose a subheading under Details to view specific guides.

      1. Returns to the main menu screen.
      2. Required Test Details.
      3. Test Details entry boxes.
      4. Test Details save button.
      5. Test Details load button.
      6. Clear old Test Details.

      Detail Entry

      • Click the 'Test Detail Entry' box.
      • Enter the required information in the fields provided.

      Detail Save

      • Click the 'Save' button to save your details.
      • Confirm the save action when prompted.
      • Your details will now be saved and can be accessed later.

      Detail Load

      • Click the 'Load' button to retrieve saved details.
      • Select the details you want to load from the list.
      • Confirm the load action when prompted.
      • Your selected details will now be displayed.

      Detail Reset

      • Click the 'Reset' button to clear all entered details.
      • Confirm the reset action when prompted.
      • All fields will be cleared and ready for new entries.

      Automation

      Overview of the Automation interface and functions. Choose a subheading under Automation to view specific guides.

      1. Returns to the main menu screen.
      2. Test list display.
      3. Test Details overview.
      4. Test list search bar.
      5. Test load button.

      Automation Setup

      • Select the test you want to perform.
      • Check test description if it aligns with your requirements.
      • Click 'Load' to go to the Alarm page.

      Note: The test description can be cross-referenced with the work procedure description.

      Alarm

      Overview of the Alarm interface and functions.

      1. Returns to the main menu screen.
      2. High alarm threshold settings.
      3. Low alarm threshold settings.
      4. Back seat alarm activation.
      5. Temperature monitor activation.
      6. Operation mode selection.
      7. Test pressure input.

      Note: Alarm settings automatically adjust based on the selected operation mode and programme, but can be manually modified if required.

      Manual

      • Select 'Manual' from the operation list.
      • Enter test pressure.
      • Check automated alarm settings based on your test.

      Hydraulic

      • Select 'Hydraulic' from the operation list.
      • Enter test pressure.
      • Enter actuator pressure.
      • Check automated alarm settings based on your test.

      Torque

      • Select 'Torque' from the operation list.
      • Enter test pressure.
      • Enter torque limits.
      • Check automated alarm settings based on your test.

      Note: You can switch between torque limit and position.

      Pneumatic

      • Select 'Pneumatic' from the operation list.
      • Enter test pressure.
      • Check automated alarm settings based on your test.

      Note: You can monitor maximum torque if using a torque transducer.

      Electro-Mechanical

      • Select 'Electro-Mechanical' from the operation list.
      • Enter test pressure.
      • Check automated alarm settings based on your test.

      Note: You can monitor maximum torque if using a torque transducer.

      Backseat & Temperature

      • Click the 'Backseat' button.
      • Enter backseat High and Low alarm thresholds.
      • Click the 'Temperature' button.
      • Enter temperature High and Low alarm thresholds.

      SEW

      1. Motor speed.
      2. Acceleration time.
      3. Deceleration time.
      4. Setpoint torque after motor release.
      5. Distance over which the torque value is ignored.
      6. Motor speed for initial cycle.
      7. Duration the torque motor applies the setpoint torque.

      Previous PDF

      • Previous PDF allows users to view and compare past test results.

      Historical Trend

      • Navigate to the desired folder containing your CSV files.
      • Select your desired CSV files for the trend and test detail analysis.
